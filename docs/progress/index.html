      How these estimates are calculated

      Expected pull requests for a stream is the planned count, or the actual open-plus-merged count if more land. Progress is (merged + half of the open pull requests) divided by that expected count. A stream with no open or merged pull request stays at 5% while it is still coding. It stops at 95% while a pull request is open. Once nothing is open and the latest pull request merged, it reads 100%, even when fewer merged than the planned count. status.json beside this page can mark a stream or plugin track done and set its finish time. A done flag is the source of truth: the page shows 100% and Done at that time, with no ETA. Closed pull requests that were not merged stay in the list and do not move the percentage. Plugins is the average of four tracks. Starter is a branch that ends with -plug and not -privacy-plug, -chat-plug, or -media-plug, planned at 5 pull requests. Privacy, Chat, and Media are planned at 4 each. A chip lights up when a merged pull request in that track names the plugin. While this tab is visible, pull requests refresh every minute. A hidden tab pauses, then refreshes when you come back. Published releases refresh at most every 10 minutes, and again when every workstream first reaches 100%. The page saves a snapshot in this browser and waits out GitHub’s limit. A version’s update time is the gap from the previous release’s publish time; the first release is the start. The total adds those gaps to the live in-progress timer. An agent’s ETA is the time since its first pull request, divided by the fraction done, minus the time already spent. That estimate counts down every second until the next refresh. The 3.0 ETA is the latest of the workstream and plugin-track estimates. A finished agent shows Done and the time its last pull request merged. ETAs are computed from pull requests the page already loaded. Each workstream and plugin track also shows the current task: the title of its latest open pull request, or else the latest commit message on its branch, plus the last three commit messages. Working time starts at the earliest commit or pull request on that task and counts up every second. Total time starts at the agent’s first commit or pull request. A finished agent shows Done and freezes that total at the last merge. An agent with nothing open and no recent push shows Idle. Branch names and recent pushes are saved for 15 minutes. The current branch is compared with main so the commits on that task come back in one request. If the branch is already in main, only its latest commit message is kept. Those lookups stop when fewer than 12 GitHub requests remain. The activity refresh itself is skipped below 18, so the page stays inside the unauthenticated hourly limit. Finished 3.0 streams stay in the 3.0.0 line of the version history. The main view lists only agents that are still in progress.
